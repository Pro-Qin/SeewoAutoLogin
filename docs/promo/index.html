账号管理

谁上这节课，谁排在最前面

生效区最多 6 个账号直达希沃；其余账号留在备用区，托盘右键一键切换、随时提上来。

分组管理

生效区 / 备用区两栏，拖动排序、备注与标签一目了然。

列表轮换

多账号场景下按组轮换展示，避免总排在最后的账号被冷落。

账号巡检

一键校验每个账号的密码与令牌，失效的直接标红并说明原因。

两种添加方式

密码添加，或者扫码添加

用希沃官方 App 或微信扫一扫即可登录并保存令牌，到期自动续期，不用反复扫码。

扫码登录

120 秒倒计时，过期、拒绝、网络异常都有明确状态提示。

批量导入

粘贴多行「账号,密码」一次导入，开学前几分钟配好全班设备。

凭据与隐私

密码只留在这台电脑上

账号密码用 Windows DPAPI 加密落盘，设置口令用 PBKDF2 加盐哈希；网关只服务本机回环，局域网里伪造请求会被直接拒绝。

DPAPI 加密

密文与当前 Windows 账户绑定，拷走文件也解不开。

仅本机可用

非回环来源一律 403，账号列表与令牌不会外泄。

更新可校验

下载按网络择优换源，逐字节校验 SHA256，不匹配自动重下。
