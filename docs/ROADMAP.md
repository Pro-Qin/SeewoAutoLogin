# 宣传片方案 v2：从「截图幻灯片」升级到「真机运镜」

## 旧版为什么不够高级

三处硬伤，都在素材与运镜，不在音乐：

1. **素材是静态截图**。界面图片贴上去，最多做个平移缩放，看着像 PPT。
2. **镜头没有纵深**。所有元素都在同一平面，没有前景、背景、景深。
3. **没有真实世界的锚点**。观众看不到「老师真的在用它」，只看到一张张界面。

## 新方案的三个核心手段

### 一、用真实屏幕录制替代截图

用 60fps 录下真机操作（希沃登录界面出现账号头像 → 点击 → 进入），再抽帧放进片子里。
真实录屏有两点截图给不了：鼠标移动的轨迹、界面响应的瞬间延迟。观众能感觉到「这是真的」。

录制要点：
- 用 4K 录制再缩到 1080p，边缘更锐；
- 关闭桌面图标与无关窗口，任务栏用深色；
- 关键动作放慢 0.5 倍录，后期加速到正常，运镜更稳。

### 二、给界面卡片做 3D 运镜

界面不再平铺在画面上，而是作为**空间中的一块面板**，用 CSS 3D 变换做：

```css
/* 关键：perspective 让 transform 产生真实纵深 */
.panel {
  transform: perspective(1400px) rotateY(-14deg) rotateX(6deg) translateZ(0);
  transform-origin: 50% 50%;
  will-change: transform;
}
```

镜头语言：
- **推进**：从 `translateZ(-420px)` 推到 `0`，配合 `rotateY` 从 -22° 收到 -6°，模拟摄影机绕到正面；
- **掠过**：面板横向平移时保留轻微旋转，产生视差；
- **定格**：关键信息出现时停止运镜 0.3 秒，让眼睛落定。

缓动统一用 `cubic-bezier(.23,1,.32,1)`（ease-out-quint），进入快、落定稳。

### 三、分三层景深

| 层 | 内容 | 动效 |
|---|---|---|
| 背景 | 深色渐变 + 网格 + 光晕 | 极慢横移（20 秒走完一屏） |
| 中景 | 界面面板、账号卡片 | 主运镜区 |
| 前景 | 数据粒子、光斑、扫光 | 快速掠过，`blur(2px)` 制造失焦 |

三层速度不同才有纵深。前景带模糊是关键 —— 全清晰的画面永远像平面。

## 分镜（20 秒）

| 时间 | 画面 | 声音 |
|---|---|---|
| 0.0-2.4 | 三句疑问句快闪（沿用现有节奏） | 秒针 tick + 重击 |
| 2.4-3.2 | 「停下。」+ 闪白 | 冲击音 + 镲片 |
| 3.2-6.0 | **真机录屏**：希沃登录界面出现三个头像 → 鼠标移过去 → 点击 → 进入桌面 | 音乐进入 drop |
| 6.0-9.0 | 面板 3D 推进：主界面（四项自检全绿） | 和弦切换 + 镲片 |
| 9.0-12.0 | 三张卡片横向掠过：多账号 / 扫码 / 保活 | 每张卡一次轻击 |
| 12.0-15.0 | 保活可视化：时间轴上节点逐个点亮（表示续期成功） | 定音鼓滚奏渐强 |
| 15.0-17.5 | 面板推远，Logo 居中 | 全奏 |
| 17.5-20.0 | 仓库地址 + 二维码，画面渐隐 | 3 秒长尾 |

## 声音：加一层音效

现在的配乐只有音乐层，缺**音效层**。高级感很大一部分来自音效：

| 时机 | 音效 | 合成方式 |
|---|---|---|
| 镜头切换 | whoosh | 带通噪声 + 快速衰减（0.25s） |
| 卡片出现 | 轻击 | 短正弦 + 极快衰减（0.08s） |
| 自检灯点亮 | 叮 | 2kHz 正弦 + 指数衰减 |
| 重击点 | impact | 低频下坠 + 镲片（已有） |

音效单独做一条轨，**在音乐的重音之间穿插** —— 全部落在拍点之外的半拍上，听起来才有层次。

## 落地路径

现有管线（`docs/promo/`）已经具备：逐帧渲染、拍点对齐、音乐合成。新方案只需替换素材与运镜：

```bash
# 1. 录真机素材（新增）
#    用 Windows 自带录屏或 ffmpeg gdigrab，录 4K/60fps，再抽成 PNG 帧序列

# 2. 改 film-v3.html：截图换成录屏帧、加 perspective 运镜
python make-music-v5.py            # 音乐（已有）
python make-sfx.py                 # 音效层（新增）
node render-film.mjs film-v4.html 20
ffmpeg -y -framerate 30 -i frames/%05d.jpg -i music-v5.wav -i sfx.wav \
  -filter_complex "[1:a][2:a]amix=inputs=2:weights=1 0.42" \
  -c:v libopenh264 -b:v 8M -pix_fmt yuv420p -c:a aac -b:a 192k -shortest \
  seewo-promo-v2.mp4
```

工作量估计：录屏与剪辑 1 小时，运镜调试 1 小时，音效合成 30 分钟。

# 还值得做的东西

## 一、能直接减少你日常麻烦的

| 想法 | 为什么值得做 |
|---|---|
| **凭据有效期预警** | 已经从日志积累「凭据年龄」，攒够数据就能算出希沃凭据的真实寿命。到那之后可以在快过期时提前提醒，而不是等账号突然不可用。 |
| **一键重新扫码** | 账号卡片上直接给「重新扫码」按钮，扫完自动替换该账号的凭据，不用删了重加。 |
| **账号列表导出/导入（加密）** | 换电脑时不用一个个重新录。用 DPAPI 或口令加密导出，只有本人能导入。 |
| **启动自检失败时的自助修复引导** | 现在自检红了只给「一键修复」。可以把失败原因翻译成人话，直接告诉用户点哪里。 |

## 二、面向「一个班/一个学校」的场景

| 想法 | 说明 |
|---|---|
| **教师口令** | 切换账号前要求输入口令，避免学生随手点开老师的账号。 |
| **按科目/班级标签分组** | 已有的标签字段可以升级成筛选器，一个班一套账号。 |
| **CSV 批量导入** | 现在支持粘贴导入，CSV 文件会更适合开学批量配置。 |
| **课表联动** | 按当前时间自动把对应老师的账号排到第一位。 |

## 三、工程质量

| 想法 | 说明 |
|---|---|
| **单元测试** | 权限判断、配置读写、凭据加解密、拍点表生成这些纯逻辑部分，值得有测试兜底。 |
| **崩溃自动上报（本地）** | 把未处理异常写入独立日志并提供一键打包，方便像今天这种「别人电脑上报错」的场景定位。 |
| **安装包静默升级** | 现在检查更新后需要手动下载安装，可以做成下载完自动装（需保留取消入口）。 |

## 四、可以不做但要知道的

- **不要做云同步**：账号密码一旦离开本机，免责条款和信任基础都会变。现在的定位（数据只留本机）反而是优势。
- **不要做自动登录到桌面**：绕过希沃登录界面的做法既不稳定，也容易触碰授权边界。
