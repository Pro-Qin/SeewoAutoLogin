# 隐私政策

## 本地存储

- 账号、密码、扫码凭据、日志、配置只保存在本机 `%LOCALAPPDATA%\SeewoAutoLogin`。
- 密码使用 v2 加密：每安装随机主密钥 + DPAPI 绑定当前 Windows 用户 + AES-256-GCM。
- 不收集账号、密码、token，也不上传这些内容。

## 联网行为

- 仅在检查更新与下载更新包时联网。
- 更新检查访问 GitHub 官方 API 或已配置的镜像；安装包下载走 GitHub 官方直链并由镜像加速。
- 不使用第三方统计 SDK，不上报遥测。

## 诊断包

- 诊断包包含日志摘要、网关状态、hosts 状态、账号健康状态等排障信息。
- 密码、token、手机号会打码；账号备注名等元数据可能保留。
- 是否上传诊断包由用户决定；上传前请自行确认内容。

## 用户权利

- 可在设置中导出/导入配置与账号（账号导出使用独立口令加密）。
- 可在设置中删除账号或恢复出厂设置。
- 卸载程序会清理本地数据目录、hosts 映射与开机自启计划任务。

## 联系方式

隐私相关问题请通过 GitHub Issues 提交。
