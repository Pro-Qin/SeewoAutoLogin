# 兼容性矩阵

> 本文件描述的是 **`win7` 分支**（.NET Framework 4.8）。主干分支要求 Windows 10 19041+，见 `main`。

## 运行环境

| 项目 | 要求 |
|---|---|
| Windows | Windows 7 **SP1** / 8.1 / 10 / 11，**64 位**（安装包 `MinVersion=6.1sp1`，32 位系统直接拒绝安装） |
| .NET | **.NET Framework 4.8**（Win7 默认不带；安装包会检测并引导下载） |
| WebView2 | 主界面需要。Win10/11 由程序自动安装；**Win7/8.1 上只支持 109 系列**（110 起不再支持这些系统），需手动或离线安装 |
| 管理员权限 | SSO 网关、hosts 写入、计划任务需要 |

## 与主干的差异

| 项目 | main | win7 分支 |
|---|---|---|
| 目标框架 | .NET 8（Windows 19041+） | .NET Framework 4.8 |
| 发布形态 | 单文件 exe | exe + 依赖 DLL 目录（免安装版为 zip） |
| 自动更新 | 走主干 Release | 走 Win7 分支自己的 Release（发布 tag 带 `-win7`，不会被升级到主版本） |
| TLS | 由系统决定（Win10+ 默认 TLS 1.2 及以上） | 保持 `SystemDefault`（不硬编码协议），并在 Win7/8.1 上按需启用系统 Schannel 的 TLS 1.2 客户端 |

## 希沃客户端

| 希沃白板版本 | 状态 | 备注 |
|---|---|---|
| 5.2.x | 已验证 | 当前开发环境 |
| 更早 5.x | 待验证 | 建议先用诊断包确认接口是否一致 |
| 6.x | 待验证 | 接口变化时需适配 |

## 已知问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 快捷登录入口不出现 | 网关未监听 24300 或 hosts 映射丢失 | 主界面自检栏一键修复；确认以管理员运行 |
| 端口 24300 被 EasiAgent 占用 | 希沃侧 SSO 进程占用 | 程序会询问是否结束；更新后启动会自动接管 |
| 更新后快捷登录失效 | 旧版本未保留 hosts / 未接管端口 | v1.13.0 起已修复，更新后自动接管 |
| 账号显示密码已修改 | 旧版本把网络失败误判为凭据失败 | v1.12.11 起网络失败改为黄色状态并退避重试 |

## 诊断

主界面 `设置 -> 维护与诊断` 可导出诊断包；其中包含网关状态、hosts 映射、账号健康状态与日志摘要。
