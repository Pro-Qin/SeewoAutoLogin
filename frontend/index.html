启动与运行

程序怎么启动、窗口怎么显示
开启后程序启动与运行期间定时自检：hosts 缺失自动重建、网关异常自动重启、端口被 EasiAgent 占用时自动接管、开自启缺失自动重建，无需打开主界面。
开启后每次退出都会删除本程序写入的 local.id.seewo.com 映射，避免残留；下次启动会自动重新写入（需要管理员权限时可能失败）。

外观与显示

希沃界面上的提示与动效
关闭后仅在托盘菜单「显示遮罩」手动触发
开启后关掉耗性能的界面动效：粒子背景、毛玻璃、开场动画、卡片入场与页面切换过渡、提醒的滑入滑出等，界面改为「直接出现」。适合教室一体机或较老的机器；不影响任何功能，只是少一些观感。

安全

一台设备多人使用时，避免别人点开你的账号

更新

新版本怎么检查和安装
默认使用 GitHub 官方接口（api.github.com），失败时回退 jsDelivr 只读取版本号；下载地址会自动择优。
开启后：发现新版本会后台自动下载，校验通过即静默安装并自动重启回托盘；更新后自动接管希沃快捷登录，不弹安装向导。

数据与迁移

换电脑、备份，或者从旧机器搬过来
卸载或迁移前请运行卸载程序，避免残留 hosts 映射与开机自启任务。
查看应用保存的配置备份，可恢复到指定时间点（恢复会覆盖当前配置）
